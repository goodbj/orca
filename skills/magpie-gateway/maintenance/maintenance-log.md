## 故障记录

### 问题：agent2api 数据库加密导致导入失败

- **时间**: 2026-11-03 09:00
- **现象**: 直接替换 DB 文件后内置提供商丢失
- **原因**: 数据库加密/签名机制
- **解决**: 通过 SQL 合并 `accounts` 表，避免直接替换
- **预防**: 后续迁移使用 API 或数据库合并方式

### 问题：Web 密钥每次重启变化

- **时间**: 2026-11-03 08:50
- **现象**: 容器重启后 Web UI 链接失效
- **原因**: magpie 默认每次生成随机密钥
- **解决**: 设置 `MAGPIE_WEB_KEY` 环境变量固定密钥
- **预防**: 部署脚本自动生成固定密钥

### 问题：端口 3425 公网无法访问

- **时间**: 2026-11-03 08:30
- **现象**: curl 返回 000 超时
- **原因**: 云安全组未开放 3425 端口
- **解决**: 在 Oracle Cloud 控制台添加入站规则
- **预防**: 部署文档注明安全组配置步骤
